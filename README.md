# Traffic Emergency Intelligent Agent V6.0

## 📖 Introduction
A desktop-level traffic emergency decision support system independently developed by a freshman at Beijing Jiaotong University. Built with Python, DeepSeek LLM API, and DuckDuckGo search engine.

## ✨ Core Features
- **Multi-threading Architecture**: Prevents GUI freezing during API calls.
- **Privacy Protection**: Regex engine for data masking (license plates/phones).
- **Offline Fallback**: Switches to local mock database when network fails.
- **Multi-format Export**: Export reports to .txt.

## 🛠️ Tech Stack
- **Language**: Python 3.10+
- **GUI**: Tkinter
- **AI Model**: DeepSeek API
- **Search**: DuckDuckGo Search API
